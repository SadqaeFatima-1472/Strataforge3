THE PROBLEM

What happens after deployment

Data shifts. Patterns evolve. User behavior changes. The model's learned relationships break down — but without observability, nobody notices.

P0

Deployment baseline

Model trained and validated. Strong ROC-AUC on held-out test data.

P1–2

Performance begins shifting

Underlying feature distributions move. Without observability, this signal is invisible.

P3–4

Degradation compounds

Recall and precision begin moving in directions that look fine in aggregate but aren't.

P5
Alert fires

Recall alert triggers

Recall drops below the defined safety threshold. Sentinel fires the alert before losses compound.

API ACCESS

Integrate Sentinel into your stack

Run scoring, observability checks, explainability queries, and threshold diagnostics programmatically.

# Observability check — POST /v1/sentinel/observe
import requests

response = requests.post(
    "https://api.strataforge3.com/v1/sentinel/observe",
    headers={"Authorization": "Bearer <your_api_key>"},
    json={
        "model_id": "fraud_xgb_prod_v2",
        "period": "2025-Q2",
        "features": ["amount", "velocity_24h", "merchant_risk"],
        "alert_threshold_psi": 0.25,
        "explain": true
    }
)

# Returns: recall trend · alert status · signal drift per feature · feature attribution
data = response.json()
print(data["recall_current"], data["alert_status"], data["top_signal_change"])
